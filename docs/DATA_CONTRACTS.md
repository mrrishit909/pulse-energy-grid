# Data contracts

Grain, keys, units and rules. Enforced in `tests/` (pytest). JSON Schemas (draft 2020-12) are generated by `pipelines/contracts.py`
into `data/contracts/*.schema.json`, one per published artifact, and every artifact is validated against its schema.

## Interim tables (not published)
### `data/interim/eia_long.parquet` (ingestion output, raw as published)
| Field | Type | Semantics |
|---|---|---|
| ba | str | `CISO` or `ERCO` |
| kind | str | `D` demand, `DF` EIA day-ahead forecast, `NG` total net generation, `TI` total interchange, `GEN` net generation by fuel |
| fuel | str | fuel code for `GEN` (NG, COL, NUC, OIL, OTH, SUN, WAT, WND), else empty |
| ts_utc | timestamp (naive, **UTC**) | start of the hour. EIA publishes hour-ending-agnostic ISO8601 hours in UTC |
| value | float, nullable | MWh in the hour (= average MW). Unit as published; no rescaling |

### `data/interim/hourly.parquet` (cleaned, one row per BA x UTC hour on the full grid)
Wide table: `ba, ts_utc, demand, demand_forecast, net_gen, interchange, gen_{fuel}...` plus for each series a flag column
(`ok`, `null`, `missing`, `flagged`, `imputed`). Rows exist for **every** UTC hour of the window (40,776 per BA); missing source rows are NULL with flag `missing`.
`temp_c`, `dew_c` (population-weighted BA values) and `local_ts`, `local_date`, `local_hour`, `local_dow` are added.

## Cleaning rules (applied in this order, each counted in the ledger)
1. **Grid**: expected slots = every UTC hour from 2021-01-01T00 to 2025-08-26T23. Slots absent from the source are `missing_slots`.
2. **Null**: source value null -> `null_value`.
3. **Range**: demand, net generation must be > 0 and demand within [0.2, 2.0] x the series median; else flagged `flagged_outlier` (rule `range`).
4. **Spike (hampel-style)**: for demand, forecast and net generation, a value is flagged when it differs from the median of the same local hour-of-week across the
   surrounding +/- 3 weeks by more than 35 percent *and* differs from both neighbours (previous and next hour) by more than 20 percent in the same direction (rule `spike`).
5. **Short-gap imputation**: runs of at most 3 consecutive null / missing / flagged hours in demand, forecast, net generation and temperature are filled by linear interpolation and flagged `imputed`. Imputed demand hours are available as lag inputs but are **excluded from forecast targets and metrics**. Longer runs stay NULL.
6. Flagged values are **never silently dropped**: they are retained in interim with a flag, counted in `reconciliation.json` and `quality.json`, and excluded from aggregates and modelling targets.

Invariants (tested exactly): per series `grid_slots = raw_rows + missing_slots` and `raw_rows = kept + null_value + flagged_outlier`.
Fuel series (`GEN`) are checked for nulls and extreme spikes but negative values are physical (e.g. station service, storage charging reported in OTH) and are kept.

## Published artifacts: `site/public/data/` (schema version `v1`, each under 400 KB gzip)
| Artifact | Grain | Key | Contents |
|---|---|---|---|
| `meta.json` | n/a | n/a | window, split dates, BAs, stations, attribution, per-artifact tags and byte sizes |
| `facts.json` | BA | BA | every headline number used in site copy (single source of truth) |
| `reconciliation.json` | BA x series | (ba, kind, fuel) | source ledger (grid slots, raw rows, kept, excluded by reason), fuel-sum vs total, demand + interchange balance, weather coverage |
| `quality.json` | BA | BA | gap runs, DST day counts and transitions, outlier rules with counts, example spikes |
| `demand_profile.json` | BA x date, month x hour, hour of week | local time | daily mean/peak/min demand and temperature, mean demand by (month, local hour) and by local hour-of-week, annual stats |
| `fuel_mix.json` | BA x fuel | fuel | annual share, mean MW by (month, local hour) per fuel, capacity proxies, evening ramp statistics |
| `weather_relation.json` | BA x hour | local hour | per-hour cooling/heating degree-coefficients, temperature bins of demand, percent change per deg C |
| `forecast_eval.json` | BA x model | model id | MAE, MAPE, RMSE, bias, peak-hour MAPE, by-hour and by-month MAPE; interval coverage raw and conformal; paired comparison vs EIA with bootstrap CI; permutation importance |
| `forecast_samples.json` | BA x test week | label | hourly actual, EIA, seasonal-naive, GBM P50/P10/P90 for 3 labelled weeks; daily test errors |
| `dispatch_model.json` | BA x class, day | id | generator classes, battery, assumptions (SIMULATED), reference days (observed demand/renewables), scenarios, formulation, reference LP text |
| `dispatch_results.json` | BA x day x scenario | (ba, day, scenario) | optimal dispatch, battery SoC, curtailment, unserved, shadow price per hour, cost breakdown, CO2 |
| `dispatch_test_vectors.json` | vector | n/a | inputs and expected outputs for the browser HiGHS parity test |
| `grid_topology.json` | bus / branch | id | pglib IEEE 14-bus case, labelled illustrative |

Units: demand and generation MW (hourly average; MWh per hour); temperature degC; costs USD; prices USD/MWh; CO2 tonnes; battery energy MWh; SoC arrays have 25 entries (hour 0 start through hour 24 end).
Time: all stored timestamps are UTC unless the field is named `*_local` or the artifact says local. Local conversions use the IANA zones `America/Los_Angeles` (CISO) and `America/Chicago` (ERCO). The CISO footprint spans a single time zone; ERCOT is in Central Time (a small part is in Mountain Time, ignored).
Index conventions: `month_hour_mean_mw[(month-1)*24 + local_hour]`, `how_mean_mw[dow*24 + local_hour]` with dow 0 = Monday.

## Honesty tags
Every artifact has `tags`: field group -> OBSERVED | DERIVED | PREDICTED | SIMULATED | SYNTHETIC (combinations joined by `/`).
Examples: demand series OBSERVED; capacity proxy DERIVED; forecasts PREDICTED; dispatch results and all cost, heat-rate, ramp, battery assumptions SIMULATED.
`gbm_perfect_weather` is PREDICTED and carries `available_at_forecast_time: false` (it uses observed target-hour temperature as a stand-in for a perfect weather forecast and is an upper bound, not a deployable model).

## Reproducibility
`uv run python -m pipelines.run_all` rebuilds everything from `data/raw`. Outputs are byte-identical across runs (sorted keys, fixed seeds, `generated_at` = latest raw retrieval time from the manifest).
Raw files are gitignored and re-creatable (`--fetch`); checksums in `data/manifests/`.
